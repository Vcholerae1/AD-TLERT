# ERT Examples

This directory contains two groups of runnable ERT examples:

- `single_time/`: single-time forward modeling and inversion.
- `window_363/`: inversion of 365 time steps with a window size of 3 and a
  step of 1, producing 363 windows.

Run all commands from the repository root. Outputs are written to `result/`.
Use `--project-root`, `--forward-dir`, and `--output-dir` to override the
default paths.

The pyGIMLi windowed inversion also requires `PyHydroGeophysX`. ResIPy/R2
requires Wine on Linux. ResIPy 3.6.6 requires NumPy 1.x, which conflicts with
the JAX/NumPy 2.x requirements of the main environment, so install it in a
separate environment:

```bash
uv venv .venv-resipy --python 3.11
uv pip install --python .venv-resipy/bin/python "resipy==3.6.6" psutil
```

## Single-Time Forward Modeling and Inversion

Deepert forward modeling and inversion:

```bash
.venv/bin/python example/single_time/forward_deepert.py
.venv/bin/python example/single_time/inversion_deepert.py
```

pyGIMLi forward modeling and inversion:

```bash
.venv/bin/python example/single_time/forward_pygimli.py
.venv/bin/python example/single_time/inversion_pygimli.py \
  --data-file result/1_single_forward_pygimli/synthetic_ert_terrain_vardz.dat
```

ResIPy/R2 inversion:

```bash
.venv-resipy/bin/python example/single_time/inversion_resipy.py
```

The ResIPy example only performs inversion. It reads the generic NPZ
observation data generated by Deepert. This repository does not include a
separate ResIPy forward implementation.

## 363-Window Inversion

The following commands read 365 time steps from
`result/1_timelapsedERT_forward_deepert`. The defaults,
`--window-size 3 --window-step 1`, produce 363 windows.

```bash
.venv/bin/python example/window_363/inversion_deepert.py
.venv/bin/python example/window_363/inversion_pygimli.py
.venv-resipy/bin/python example/window_363/inversion_resipy.py
```

The ResIPy entry point supports resuming interrupted runs. It skips any window
that already contains `wNNN/summary.json`.

All three implementations are computationally expensive. Before a full run,
use `--max-timesteps` with Deepert or pyGIMLi, or increase `--window-step`
with ResIPy, to run a smaller validation case.
